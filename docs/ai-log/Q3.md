# Q3 — Arrays and enumerations chosen by the instance (task of igs-iec61850-mms)

## Prompt

Run task Q3 of `IMPLEMENTATION.md` (depends on Q1, A2): arrays served with their length, enumerations named by the data object where the
namespace gives the name. Done when a served array reads and writes with its length checked.

## Sources

- IEC 61850-7-2 §6.2.5.5 (arrays: `ARRAY 0..m OF p`, the element type is not an array; the number of members is the instance's count) and
  its table of types (the bType of the element and the count).
- IEC 61850-8-1 §8.1.2.7 (the array maps to an MMS array per functional constraint), §8.1.3 (the alternate access, D-009).
- The catalogue: six array attributes (`hstVal`, `hstRangeC`, `crvPts` with the size attribute `maxPts`); 93 data objects of ENC, ENG and
  ENS with an enumerated attribute that has no name of its own.

## Summary

- **Arrays** (`model/mod.rs`, `model/layout.rs`): `Node::Array { count, element }`; the count is the integer that the instance gives to the
  size attribute (`DataObjectSpec::with_integers`, read from the SCL `DAI` of the data object by `integer_values` in `scl/build.rs`). Without
  the size, or above 4096 elements, the array is refused (`Unsupported`). The layout describes it as an MMS array, and its initial value holds
  that many zero elements (`default_value`). One array is one variable.
- **Enumerations**: checked on the catalogue. Every enumerated attribute of ENC, ENG and ENS has a name, from its own type or from its data
  object (`underlying_type`), for all 93 data objects. An SCL-based mechanism that took the values from the `EnumType` was written and then
  removed: nothing in the namespace reaches it.
- **Writes**: the MMS layer checks a whole-array write against its element count (`vmd/conform.rs`, `array_conforms`). The test in
  `tests/updates.rs` applies three points and refuses two, through the served model.
- **Tests**: `model.rs`, `an_array_has_the_number_of_elements_its_instance_gives`; `updates.rs`, `an_array_is_updated_with_its_number_of_elements_and_a_wrong_number_is_refused`.
  The common test model has a curve node `PTTR1` with three points, used by the update test.

## Not done

- The access to one element of an array (alternate access, D-009) is refused.

## Decision and confidence

D-047 in `PROVENANCE.md`. The count rule is high-confidence (7-2 §6.2.5.5); the reading of the size as an instance value is medium.
