# A5 — Application event path and clock source (task of igs-iec61850-mms)

## Prompt

Run task A5 of `IMPLEMENTATION.md` (dependency A3): a non-blocking handle to update values, qualities and timestamps from
application tasks, with the snapshot rule of MODEL-006; the clock-source trait of TIME-001 and a host-clock implementation
(TIME-002). Done when updates from another task are seen consistently by reads and the AT-17 timestamp cases pass.

## Summary

- Core, `time`: the `ClockSource` trait, `FixedClock` (a reading its owner sets, which models the loss and the recovery of
  synchronisation), and `check_quality` / `ClockError` (an accuracy above 24 bits is refused at the source). D-014.
- Async, `clock`: `HostClock`, which reads the system time with the quality the operator declares for the host; the default
  is not synchronised. D-014.
- Async, `updates`: `Updater`, cloned into the application's tasks. An update is one node's changes, checked first (name,
  type, defined enumeration values, one node), applied to a copy under the node's lock, with a revision. D-015.
- Async, `model`: each served node carries its revision (`NodeValue`); the served variables and the updater share the
  node's value. `ServedModel::updater()` gives the handle, and `serve` returns it with the VMD.

## Tests

- Core: 5 tests (`tests/time.rs`): each quality flag at its bit, the round trip of each flag combination through the
  timestamp, the accuracy bound (25 refused by the clock and by the octet), the refusal of an invalid quality with the reading
  kept, and the loss and recovery of synchronisation in the next stamp.
- Async: 4 tests (`tests/updates.rs`): an update read as one state (value, quality, time); a refused update changes nothing
  and takes no revision; types, undefined enumerations and the single-node rule; and a reader that never sees a measurement
  without the time of its update, while 300 updates run against 300 reads.
- Async: 4 tests (`tests/clock.rs`): the default host quality, the declared synchronisation, the refusal of accuracy 31, and
  the stamp of the host with the declared quality.
