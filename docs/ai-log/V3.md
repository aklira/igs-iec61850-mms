# V3 — Robustness and performance evidence (task of igs-iec61850-mms)

## Prompt

Run task V3 of `IMPLEMENTATION.md`: fuzz targets for the core decoders and SCL, and the measurements of SPECIFICATIONS §12.4 with their workload
and hardware. Done when fuzzing runs clean for the recorded duration, and the results are recorded, no target invented.

## Summary

- Fuzz targets in `fuzz/fuzz_targets/` (nightly, cargo-fuzz 0.13.2; the crate is outside the workspace, as before):
  - `scl_parse` (S1, existing): parse with bounded limits.
  - `scl_build` (new): parse, then the checks, then the model build; the build runs only on a document the checks accept.
  - `report_codec` (new): the bit strings of the options and the triggers, the reasons, the bit count, the binary time and the object reference
    on arbitrary bytes; two assertions, the round trip of the options and of the triggers.
  - `urcb_events` (new): an unbuffered report control block fed with sequences of requests, notifications, timers and lost associations, on a
    moving clock.
  - `control_events` (new): a control object of each of the four models, fed with requests, verdicts, changes, deferred outcomes, timers and
    lost associations.
- Measurements: `crates/igs-iec61850-mms/examples/measure.rs`, results and hardware in `docs/measurements.md`. Partial against §12.4: reports,
  buffers, secured transport and reconnection bursts are not measured, and are recorded as such.

## Fuzzing runs

kept its corpus). No crash, no timeout, no sanitizer report; the artifact directories are empty.
