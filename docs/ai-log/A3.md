# A3 — Server model (task of igs-iec61850-mms)

## Prompt

Run task A3 of `IMPLEMENTATION.md` (dependencies A2 and F3): the LD/LN/DO/DA tree with the functional-constraint views
built from the catalogue, the MMS type descriptions per node and per constraint, the presence checks (MODEL-004), and
the `Model` implementation of `igs-iso9506-mms`. Done when a model built in code gives the expected GetNameList and
GetVariableAccessAttributes answers.

## Summary

- Core (`igs-iec61850-mms-core`, `model`): `ServerModel`, `LogicalDevice`, `LogicalNode` and `DataObjectSpec`. The build
  checks the class, the data objects, the mandatory members and the names against the catalogue (D-007). Each attribute
  type is resolved to its MMS type (`model::types`, D-008), including the enumeration that a data object gives to an
  open attribute.
- Core, `model::layout`: one structure per node, ordered by the functional constraints of 8-1 Figure 4, with the
  flattened names inside the identifier limit (D-005, D-006).
- Async (`igs-iec61850-mms`, `model`): `serve` builds the VMD of a server model, with each node's variables as views of
  one value. `ServedModel` implements the `Model` of igs-iso9506-mms. `server_config` and `client_config` set the IEC
  profile, the nesting level of six and `valt` (D-009). The variables are read-only (D-010).
- igs-iso9506-mms, task N6 (commit a02e537): the identifier limit of the VMD follows its profile (D-037 there). Without
  it, the flattened names of the model longer than 32 characters were refused by the server after the codec accepted them.

## Tests

- Core: 15 integration tests (`tests/model.rs`): mandatory objects, unknown names, abstract and unknown classes, repeated
  names, optional and multiple members, the order of the functional constraints, the flattened names and their paths,
  constructed attributes, the identifier limit, the initial values, and the refusal of an unmapped type with its path.
- Async: 3 end-to-end tests over TCP (`tests/served_model.rs`): GetNameList by domain, paged, with a name of 34 characters;
  GetVariableAccessAttributes at the leaf and at the node; the same value by the node and by its flattened name.
- igs-iso9506-mms: the dispatch of GetVariableAccessAttributes with the IEC limit and with the ISO limit (service tests),
  and the name tests of the limit (N6).

## Not done here

  (A4, A6).
- The gaps listed in `docs/capabilities.md`.

## For review

- The negotiation of `valt` for named components (D-009) conflicts with the reading of IEC 61850-8-1 Table 128 in the
  profile, which requires it for arrays only. The codec keeps its rule; the reading should be settled with the maintainer.
