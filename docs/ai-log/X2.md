# X2 — Journal services over MMS (task of igs-iec61850-mms, partial)

## Prompt

Run task X2 of `IMPLEMENTATION.md` (production phase X): the log control blocks served over MMS, the journal fed from the core `Log`,
ReadJournal on the server, the gateway replay, and the class `journal` of GetNameList (G14).

## Summary

- SCL: `LogControl` and `Log` are declared (`Configuration.logs`, `Configuration.journals`), with the configuration of the block (`logName`,
  `datSet`, `TrgOps`, `intgPd`, `logEna`). A block whose `logName` names no `Log` of its node is refused (SCL-003). Tests in
  `scl_build.rs` (the declaration, the dangling reference).
- Served: each `Log` is an MMS journal of its node (capacity 512); the blocks that `logEna` enables record the changes of their data set. The
  transition of LogEna is the first entry (EVENT-DATA); a change is an entry with the reference of the member, its value and its reason code
  (Table 77 and §17.3.3.4). The entries carry identifiers that increase from one.
- ReadJournal reads the journal (`tests/logs.rs`, over MMS: three entries, with their references, values and reason codes).
- G14: the class `journal` of GetNameList lists the journals of a domain (`igs-iso9506-mms`, the VMD and the server; unit test
  `the_journals_are_listed_in_their_domain_only`, and `tests/logs.rs`). At the VMD scope the answer is refused.
- Profile: the server declares the log services (`logs: true`).
- Decision: D-056 in `PROVENANCE.md`.
