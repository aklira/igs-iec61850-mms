## Not done, and why

- **The MMS part is not done.** The server must answer `ReadJournal` (QueryLogByTime, QueryLogAfter, GetLogStatusValues) and serve the
  LCB and LOG attributes over MMS. `igs-iso9506-mms` has no journal service: the codec has the generated types for `ReadJournal`, but no
  implementation of the service, of the journal objects, or of the `EntryContent` elements (8-1 Table 155). This is a phase N in that
  repository, with its own rules and its own publication. It is a decision for the owner: start that phase, or keep the MMS journal
  services out of this release and let the core model serve the gateway in-process.
- **The gateway replay** (G2) depends on the MMS part for a downstream client to read the downstream log. Not done.
- **The SCL build** does not create the LCB or the LOG from `LogControl` elements yet (SCOPE-002 applies until then).
- **The values of the entries** are not kept by the core (the caller reads them when it appends a record, as for the buffered reports).
- **Application trigger** (§17.3.5.4): not in the core.
- **Buffer time** of the LCB (BufTm, optional in Table 78): not supported.
