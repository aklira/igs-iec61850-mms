# O5 — Embedded SNTP client (task of igs-iec61850-mms)

## Prompt

Run task O5 of `IMPLEMENTATION.md` (optional group, section O): the embedded SNTP client, RFC 5905 subset, with the accuracy of the
timestamps from the root dispersion (TIME-002, TIME-003).

## Sources

- IEC 61850-8-1 §6.4.2.2 and §6.4.3.2 (prepared text in `docs/spec/8-1`): the SNTP subset, modes 3 and 4, the accuracy from "the
  unadjusted DELTA to the SNTP Root Dispersion attribute", UDP port 123.
- RFC 5905 (public text): packet layout, offset and delay formulas, LAMBDA, short format, the receive checks of the reference code.
  Section 14 (SNTP) was read in full through the published text; it is short and leaves the checks to the implementation.
- TISSUE 1704 (`docs/spec/tissues/tissues.yaml`): the formula for the accuracy was asked and closed as not applicable; the triage asks
  for a conservative value.

## Summary

- **Core** (`crates/igs-iec61850-mms-core/src/sntp.rs`, sans-I/O): `NtpTime`, `request`, `parse`, `check_reply` (`Rejection`),
  `exchange` (offset and delay), `root_distance`, `accuracy_of` (the bits of the 2^-24 s fraction covered by the distance, rounded up;
  above one second, not synchronised), `Client` (`poll`, `receive`, `is_synchronised`, `stamp`), with `MAX_AGE` = 1024 s and
  `POLL_INTERVAL` = 64 s.
- **Host** (`crates/igs-iec61850-mms/src/sntp.rs`): `SntpClock`, a `ClockSource` whose state is the core `Client`, and `run`, the UDP loop
  on the port the caller gives (`PORT` = 123 for a real server). Locks are never held across an await.
- **Tests**: core `tests/sntp.rs` (16 tests, controlled time, the RFC formulas, each refusal, the accuracy bits); host `tests/sntp.rs`
  (5 tests over a loopback UDP server: synchronised with the accuracy of the reply; another origin and a kiss-o'-death refused; no answer
  leaves the clock not synchronised).
- **Gate**: fmt, clippy (`-D warnings`), `RUSTDOCFLAGS="-D warnings" cargo doc`, the full workspace tests, and `statements --check`
  (30 rows, every test exists). `docs/statements.md` regenerated; `docs/capabilities.tsv` and `docs/capabilities.md` updated (TIME-001 to
  TIME-003).
- **Fixes during the work**: a test expected 9 bits for 257 units of 2^-16 s; the right value is 17 (one unit of 2^-16 s is 256 units of
  2^-24 s). The test helpers were given the test-only lint allowances used by the other test files.

## Not done

- The RFC's mitigation and adaptive poll (not needed for SNTP, §14); the authentication of the replies (MAC or NTS); several servers and
  IPv6 selection.
- PTP (IEC/IEEE 61850-9-3): not implemented.
- The demonstration server still uses the host clock. The choice between the host synchronisation and the embedded client belongs in the
  PIXIT; it is not wired into the demonstration binaries.
- The leap second announced by the server (indicator 1 or 2) is not carried into the stamps.

## Decisions

D-052 in `PROVENANCE.md`. Confidence: high for the packet, the formulas and the checks; medium for the accuracy reading (the standard gives no
formula, and TISSUE 1704 was closed).
