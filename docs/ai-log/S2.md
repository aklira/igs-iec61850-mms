# S2 — Semantic checks and templates (task of igs-iec61850-mms)

## Prompt

Run task S2 of `IMPLEMENTATION.md` (dependencies S1, F3), while K2 waits for D4 as the user chose. Data-type templates resolved and
instantiated, references, namespaces, dataset members and service declarations checked; diagnostics with file, path and line
(SCL-002, SCL-003). Done when AT-12 invalid cases each give their diagnostic.

## Summary

- Schema table, generated: `norm_preparation/extract_scl_schema.py` reads the frozen 2007B schema of IEC 61850-6:2009 (xmlschema) and
  writes `crates/igs-iec61850-mms-core/src/scl/generated/schema_2007b.rs`: 157 types, 9 roots, with children (occurrences
  multiplied along the groups), attributes (required, enumeration, boolean, integer range), and the element wildcard. The header keeps
  the IEC notice and the attribution; NOTICE names the file. The table is reproduced byte for byte by the script.
- Shape and lookups: `scl/schema.rs` (`TypeSpec`, `ChildSpec`, `AttrSpec`, `AttrKind`, `root_type`, `type_named`).
- Checks: `scl/validate.rs`, `validate(&Document, file) -> Result<(), Vec<Diagnostic>>`. SCL-002 structure, SCL-003 references,
  SCL-004 namespaces. All findings are returned, sorted by line; a document with any finding is refused whole. D-021.
- S1 changes needed by S2: `Element` gains `line` (the start tag, from roxmltree positions), and the parser keeps unqualified attributes
  only (namespaced ones such as `xsi:schemaLocation` are not SCL attributes). S1 tests still pass.
- Found and fixed during the work: the generator treated `choice` groups as sequences and did not multiply the occurrences of enclosing
  groups (AccessPoint required LN and ServerAt; FCDA and DA limited to 1); anonymous types (SCL, LN0 and local ones) were missing; the
  attribute wildcard of the schema is `##other` (namespaced attributes), so it does not admit an unqualified unknown attribute.
- Open for the user: whether the root attribute `release` (absent from the frozen 2007B schema) must be admitted (D-021).
