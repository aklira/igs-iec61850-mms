# D1 — Static datasets (task of igs-iec61850-mms)

## Prompt

Run task D1 of `IMPLEMENTATION.md` (dependencies A4 and S3): configured datasets as named variable lists, GetDataSetValues,
SetDataSetValues, GetDataSetDirectory, stable member order (DS-002). Done when the AT-08 static cases pass.

## Summary

- Core, `scl/build.rs`: each data set resolves its members against the model, in document order, to the variables it selects
  (`VariableRef{device, name}`). A member that selects nothing refuses the configuration (SCL-003). D-023.
- Async, `model.rs`: `ServedModel::from_configuration` serves the configuration's model and defines each data set as a static named
  variable list in its device's domain. A delete request that would match a static list is refused whole (access denied).
- Async, `client.rs`: `data_sets`, `data_set_members` (GetDataSetDirectory), `read_data_set` (GetDataSetValues). The write is the
  MMS write with the list (SetDataSetValues), as the raw client does it.
- The VMD (MMS repository) is not changed: its lists and its list read and write already exist.
