# Q2 — Classes with variants (setting groups) (task of igs-iec61850-mms)

## Prompt

Run task Q2 of `IMPLEMENTATION.md` (depends on Q1, S3): the variant of a common data class with setting groups is chosen from the
configuration; the served attributes follow it; a refusal stays for any variant not chosen. Done when an SCL file with a setting-group
object builds and the variant is named in its test.

## Sources

- IEC 61850-7-3 §7.6.1: the settings are SP (individual), SG (in a setting group, active value) and SE (edited value of the group selected
  for editing). The 7-3 text is not in the prepared texts; it was extracted from `docs/standard/IEC61850/IEC61850-7-3_2010+AMD1_2020_CSV.pdf`
  with `pdftotext -layout` (some streams are damaged; the clause is complete).
- IEC 61850-6 §8.6: the `SettingControl` of the LN0 declares the setting groups (`numOfSGs`, `actSG`).
- The catalogue: the CDCs with variants (`SPG`, `ING`, `ASG`, `CURVE`, `ENG`, `CSG`...) have one class per variant, SP, SG and SE.

## Summary

- **Model** (`model/mod.rs`): `LogicalNode::with_setting_groups(name, class, specs, groups)`; `new` keeps `groups = false`. The shape of a
  data object (`data_object_shape`): one class as before; for several variants, SP alone, or SG with the attributes of SE whose functional
  constraint is SE.
- **SCL** (`scl/build.rs`): a device whose LN0 has a `SettingControl` builds its nodes with groups; the `SettingControl` is kept in
  `Configuration.setting_groups` (device, `numOfSGs`, `actSG`), checked (`actSG` from one to `numOfSGs`; `SCL-003` otherwise). Before, it was
  refused as not built (SCOPE-002), which would have lost it.
- **Tests**: `model.rs`, `a_setting_object_takes_the_variant_of_its_device`; `scl_build.rs`, `a_device_with_setting_groups_serves_the_setting_values_as_sg_and_se`
  (with the fixture `tests/data/settings.cid`) and `an_active_setting_group_outside_the_declared_ones_is_refused`.
- **Workspace**: all tests pass (344 at the time of the last full run); clippy without error.

## Not done

- The services of the setting group control block (SelectActiveSG, SelectEditSG, SetEditSGValue, ConfirmEditSGValues, GetSGCBValues) are
  O3; the declared services are refused (SCOPE-002).
- Writes to SE are refused (no services): reads of SG and SE are served.

## Decision and confidence

D-046 in `PROVENANCE.md`. The variant rule is high-confidence (7-3 §7.6.1); the reading that SG and SE form one data object is medium.
