# A4 — Server data access (task of igs-iec61850-mms)

## Prompt

Run task A4 of `IMPLEMENTATION.md` (dependencies A3 and N4): the directory and definition services through GetNameList
and GetVariableAccessAttributes, GetDataValues and SetDataValues through Read and Write, the per-item errors of ACSI-002,
and the stateful write guard of MODEL-005. Done when AT-07 holds against the in-process client of A6.

## Summary

- Core, `model::layout`: each variable says whether a Write may change it (`writable`, D-012), its functional constraint,
  and the enumeration values it defines, with their paths inside the variable. `writable_constraint` reads the
  SetDataValues services of the catalogue. Controllable objects (the classes with 8-1 service attributes) are read-only.
- Core, `model::mod`: `Node::Enumerated` keeps the values of an enumeration; `is_controllable`.
- Core, `model::layout`: `value_at`, `set_at` and `defines_enumerations`, the accessors of the values by path.
- Async, `model`: the served variables take the writes allowed by the layout. A write checks the defined enumeration
  values, then replaces the value in the node's shared structure, so a flattened name and the node stay the same.
- Directory and definition services (D-013): the server answers GetVariableAccessAttributes on a data object (the
  attribute names) and GetNameList on a domain; the logical-node filter belongs to the client (A6).

## Tests

- Core: 6 tests (`tests/access.rs`): the constraints that take SetDataValues, a writable substitution and a read-only
  status, a controllable object read-only, the defined values of an enumeration, an enumeration inside a structure found
  by its path, a value read and replaced by its path.
- Async: 7 end-to-end write and directory tests (`tests/served_writes.rs`): a write read back, a status refused with
  `object-access-denied`, a node refused as a whole, a value of another type refused with `type-inconsistent`, an undefined
  enumeration refused with `object-value-invalid` and a defined one accepted, the results per item of a write of two items,
  and the data-object directory. The former three tests of A3 moved their environment to `tests/common`.
- Gate: fmt, clippy with `-D warnings` on all targets, the workspace tests (76 passed), `cargo deny`.
