# S3 — Model and communication parameters from SCL (task of igs-iec61850-mms)

## Prompt

Run task S3 of `IMPLEMENTATION.md` (dependencies S2 and A3; P2 for the reading of 61850-6 is now done). Produce an atomic build of the
server model, its datasets, its control blocks and its address parameters; declared services checked against what the server can
execute (SCOPE-002). Done when a sample CID builds a server that the A7 clients discover.

## Summary

- `scl/build.rs`: `build(document, file, ied, capabilities) -> Result<Configuration, Vec<Diagnostic>>`. One IED, named explicitly
  (SCL-001). Logical devices and nodes into a `ServerModel`; data sets as declared; address parameters of the connections of the IED.
  All or nothing. D-022.
- Refusals, never silent: instance values (`Val`), instances that are not in the type, template members the catalogue class does not
  instantiate, model refusals with the model's message, declared services not executed (SCOPE-002), and every declared block (not built
  by this release, so it would be lost).
- S1 change: `Element::text` keeps the direct text of an element (addresses and values are text).
- Validation (S2) helpers shared: the templates and the path helper are `pub(super)`.
- Sample: `crates/igs-iec61850-mms-core/tests/data/sample.cid`, written for the tests.
- Gaps to close before K2 (ctlModel values) and D1 (serving the data sets): recorded in D-022.
