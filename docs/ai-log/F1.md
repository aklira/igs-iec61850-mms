## Summary

Created the workspace after the model of `igs-iso9506-mms`: root `Cargo.toml`, `rust-toolchain.toml`,
`.cargo/config.toml` (the `cargo xtask` alias), `deny.toml`, and the crates `igs-iec61850-mms-core`,
`igs-iec61850-mms` and `xtask`, all empty. `PROVENANCE.md` starts with the reference standards and
D-001 (the split between a sans-I/O core and the async crate). `AGENTS.md` is local, as in
`igs-iso9506-mms`.

Choices:

- Same edition (2021) and minimum Rust version (1.85) as `igs-iso9506-mms`.
- The clippy lints of rule 8 sit in `[workspace.lints]`; the two library crates inherit them, `xtask`
  does not. `unsafe_code` is forbidden in all three crates (rule 8 of this plan is stricter than the
  MMS one, which denies it in its async crate).
- `deny.toml` allows only the licences of rule 9, with no exception yet.
- No dependency on the MMS crates yet: it comes with the first task that uses them, with the
  `[patch.crates-io]` override of IMPLEMENTATION.md §2.
- `docs/spec` is a symlink to `~/Dev/norm_preparation/docs/spec`, ignored by git, with the NSD and SCL
  schema file patterns.
- `xtask` answers `catalogue` (F3) and `statements` (V1) with "not implemented yet".
