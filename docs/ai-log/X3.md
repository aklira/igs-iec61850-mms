  including `.`, `/tmp`, `data`, `config`, `files`, `tmp`, and the name `test.txt` placed in the example's working directory with a volume.

## Findings

- The "IEC file class in the SCL model" of Q6 has no source in the prepared texts: a search of 61850-6 (the SCL schema texts) and of the
  7-x prepared texts found no file class. The task cannot be implemented as written until the maintainer defines it or drops it (a decision
  to record in section 5 of `IMPLEMENTATION.md`).
- SetFile (ObtainFile) is not implemented in `igs-iso9506-mms` (N8 covers GetFile, GetFileAttributeValues and DeleteFile). The decision to refuse
  it, as the plan allows, is not recorded yet.
- The IEC served model declares `files: false` in its profile and holds no file store. Serving files needs the file store of the sibling
  (`Vmd::add_file`) and an option that gives the files to the server. Not started.
