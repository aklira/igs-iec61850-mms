# D4 — Report encoding and delivery (task of igs-iec61850-mms)

## Prompt

Run task D4 of `IMPLEMENTATION.md` (dependencies D3 and N5): report PDUs with their optional fields, the inclusion bit string and the reasons,
sent through the observable delivery of N5 to the owning association only (RPT-002, RPT-003). Done when the vectors are built from the
standard's layout and a saturation produces a diagnostic.

## Summary

- Core, `report/encode.rs`: the results of an `InformationReport` in the order of table 74; the bit strings of tables 38 and 41; the binary time;
  the object reference. D-025.
- Core, S3: an unbuffered `ReportControl` is declared in the configuration (its options, triggers, buffer time, integrity period, data set);
  a buffered one is refused. Each variable of a data set knows its member and the triggers of its attribute from the catalogue.
- Async, `reports.rs`: the blocks of a served model, driven by the D3 state machine; the updater's changes are the notices (a bounded queue, with
  the dropped count); the reports are queued for the owner through N5's outbound; the timers and the association release follow D3.
- Async, `updates.rs`: an update reports which attributes changed.
- Async, `model.rs`: `ServedModel::from_configuration` builds the blocks; `ServedModel::reports()` is the application's handle.
