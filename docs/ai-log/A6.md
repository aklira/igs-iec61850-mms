# A6 — Client discovery and data access (task of igs-iec61850-mms)

## Prompt

Run task A6 of `IMPLEMENTATION.md` (dependency A2): the typed client API over the server, logical-device, logical-node and
data directories with `continueAfter` paging, the data definitions rebuilt from the type descriptions, the reads and writes
with per-item results, and the unknown classes kept as generic data (MODEL-002). Done when AT-07 holds on the client side,
against the server of A4.

## Summary

- Core, `discovery`: `define` rebuilds a definition from a type description in one of three states (known, unknown
  semantics, malformed) with paths; `functional_groups` reads the constraints and objects of a node; `logical_nodes` filters
  the named variables; `check_page` refuses a listing that repeats, misorders or stalls. D-016.
- Async, `client`: `IecClient` (domains, named variables, logical nodes, functional groups, definitions, reads, writes).
  `ClientError` for the failures of the whole operation; `ItemError` for each item, mapped from 8-1 Tables 26 and 27.
  `DataDefinition::accepts` checks a value against the MMS type it was rebuilt from. D-016.
- The listing reads pages of the server (64 names per page in the served model), so the paging is exercised by the tests.

## Tests

- Core: 12 tests (`tests/discovery.rs`): the leaves, the named structure, the type the server names (kept), a type MMS does
  not know (kept), the malformed cases with their paths, the nesting refusal, the groups, the logical nodes, the pages.
- Async: 9 tests (`tests/client_discovery.rs`, AT-07 client side): the domains and the logical nodes; the typed listing equal to
  the raw listing over the pages, with no repeated name; the functional groups; the definitions of a data object and of a
  measurement down to its float; the acceptance of a read value; the read results in order (a missing item is an error of its
  own); the write results per item (access violation, type conflict, undefined enumeration) with the first write visible
  afterwards; a missing node; a name that is not an identifier, refused before the request.
- Gate: fmt, clippy with `-D warnings`, the workspace tests, `cargo deny`.

## Not done here

- Typed data sets, reports and control blocks (tasks D, B and K).
- The array definitions have no served instance yet; they are tested only in the core through their type description.
