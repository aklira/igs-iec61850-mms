# A2 — ACSI types and their MMS mapping (task of igs-iec61850-mms)

## Prompt

Run task A2 of `IMPLEMENTATION.md` (dependencies A1, N3 and P3): the ACSI basic and common types, their MMS values
and type descriptions, the bit-string and enumeration rules, Quality and Timestamp. Decide and record the ambiguities
in PROVENANCE.md.

## Summary

- `acsi` (new module of `igs-iec61850-mms-core`): the basic types of 8-1 Table 15 (BOOLEAN, signed and unsigned
  integers, FLOAT32, visible, octet and Unicode strings), enumerations (standardised, extension, private), coded
  enumerations, the common types Quality (Table 44), CheckConditions (Table 43), Originator (§8.1.3.17) and Timestamp
  (UtcTime, N3). Each has a reader that refuses a wrong MMS type or an invalid value with `AcsiError`, and a
  type description for the MMS type of the row.
- The core crate depends on `igs-iso9506-mms-codec` by path (the MMS values and type descriptions); `Cargo.lock` changed
  for that dependency.
- Decision D-004: the enumeration size, the coded enumeration size, the bit-string reading rule against the NOTE of
  §8.1.2.1, and the string limits.

## Tests

- 20 unit tests in `acsi.rs`: one vector per row of Table 15, the bit positions of Tables 43 and 44, the bit order of the
  coded enumerations, the reading rules of §8.1.2.1, and the malformed values (zero size, out-of-range integers, bad
  characters, strings too long, wrong MMS type, invalid time quality, a float that is not single precision).
- Gate: fmt, clippy with `-D warnings` on all targets, rustdoc with `-D warnings`, the workspace tests, `cargo deny`
  (the licence warnings are the allowances of F1, not encountered), and the tests under Rust 1.85.

## Not done here

- The data model that uses these types (A3, A4) and the application string values of the model.
- The alternate access and the control of the values written by a client (N4, A4, control tasks).
